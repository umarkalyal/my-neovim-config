# neoscroll.nvim (smooth scrolling)

**Intro:** Adds smooth/animated scrolling for common scroll motions to make navigation feel nicer.

## Config highlights
- Loaded with default options (`opts = {}`)

## Usage
- Use normal scrolling keys (e.g. `<C-d>`, `<C-u>`, `<C-f>`, `<C-b>`, `zt`, `zz`, `zb`) as usual; neoscroll smooths supported motions by default.
- Exact behavior/mappings depend on plugin defaults; see `:h neoscroll` if you want to customize.

## Notes
- If you ever prefer instant scrolling, you can disable/remove this plugin spec in `lua/plugins/neoscroll.lua`.
